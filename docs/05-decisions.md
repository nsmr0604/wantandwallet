# 3. 前提が崩れたときの影響

| 前提 | 崩れた場合の影響 | 代替 |
| --- | --- | --- |
| yaml-yugi が ja を提供し続ける | 日本語検索ができない | 公式カード DB のスクレイピング、または手入力＋CSV |
| 公式商品ページの構造が変わる（埋め込みデータ・詳細の表記） | 新弾の定価・パック数の自動取得が失敗 | 手動入力（R-63）で継続。抽出は `scripts/fetch-releases.ts` に隔離。既定 30 パックで運用可能 |
| 商品の `price-intax` に単位が無い／表記ゆれ | パック/BOX の判別が誤る | 単位不明は `null` とし、手動選択を促す |
| カード名の表記ゆれ（別イラスト名・かな違い） | 同一カードが二重登録される | `nameNorm`＋読み（かな）＋パスコードで突合。手動マージ（S1 で検討） |
| iOS のストレージ退避が頻発する | データ消失 | JSON エクスポートの定期実施を促す。将来は同期で解消 |
| 1.3 万件の索引が大きすぎる | 初回ロードが遅い | 検索索引を名前＋パスコードに限定（セット情報を持たない） |
