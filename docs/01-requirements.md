# 1. 背景と課題

遊戯王 OCG のシングルカードを買うとき、複数の実店舗・通販を回って価格を比較している。現状の困りごと:

1. どの店でいくらだったかが記憶とスクショに散らばり、比較できない
2. 「何を何枚欲しいか」を忘れる／買った枚数を二重計上する
3. 今月いくら使ったか、あと何円使えるかが分からない
4. 次の新弾の発売日をいちいち調べている

# 2. ゴール / 非ゴール

## ゴール

- 店舗巡回中に、欲しいカードと各店の価格を**その場で数タップで記録**できる
- 巡回後に「どこが最安か」を一覧で判断できる
- 購入実績が**月次予算とカテゴリ別内訳**に自動で反映される
- 新弾の発売日を一覧・カウントダウンで把握できる
- **オフライン（電波の弱い店内）で全機能が動く**

## 非ゴール（今回やらない）

- カードの売買・マッチング機能
- デッキ構築・対戦記録
- 投資目的の相場分析・自動売買
- 複数ユーザーでの共有・SNS
- ストア配信（App Store / Google Play）

# 3. 利用シーン（想定フロー）

```
[事前] 欲しいカードを登録（数量・目標価格・優先度）
   ↓
[巡回] 店舗を選ぶ → 欲しいリストを上から順に「この店では◯円」を入力
   ↓
[判断] 比較表で最安店・差額・予算残を見て購入を決める
   ↓
[記録] 購入（店舗・数量・実価格・日付）を登録 → 予算から自動減算
   ↓
[振り返り] 月次ダッシュボードで消化率・内訳・買いすぎを確認
```

# 4. 機能要件

優先度: **M**=Must（MVP）, **S**=Should, **C**=Could（将来）

## 4.1 カードマスタ

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-01 | 日本語カード名でカードを検索できる（部分一致） | M |
| R-02 | 検索結果から 1 枚を選び、**型番（セットコード＋レアリティ）**を選択できる | M |
| R-03 | 型番が分からない／DB に無いカードは手入力で登録できる（名前・型番・レアリティ・メモ） | M |
| R-04 | カード画像は表示しない（テキストのみ。将来 C） | M |
| R-05 | 既存カードの重複登録を防ぐ（型番で一意） | M |

> 価格は**型番単位**で管理する。同じ「灰流うらら」でもノーマルとシークレットでは価格が別物のため。

## 4.2 欲しいリスト（ウィッシュ）

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-10 | カード（型番）ごとに「欲しい枚数」「優先度（高/中/低）」「目標価格」「メモ」を登録 | M |
| R-11 | 欲しいリストを優先度・追加日で並べ替え | M |
| R-12 | 購入済み枚数を差し引いた「残り必要枚数」を表示 | M |
| R-13 | 達成（必要枚数＝購入済み）にすると自動でリストから折りたたむ | S |

## 4.3 店舗マスタ

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-20 | 店舗（実店舗／通販）を登録・編集・アーカイブ（論理削除） | M |
| R-21 | 店舗に種別（実店舗/通販）、エリア、URL、メモを持たせる | M |
| R-22 | よく行く店舗をお気に入り（並び順上位固定） | S |

## 4.4 価格記録・比較

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-30 | 「店舗 × 型番 × 価格 × 日付」を 1 レコードとして記録（同一店舗の再訪は上書きせず履歴） | M |
| R-31 | 巡回モード: 店舗を選び、欲しいリストを順に価格入力していく画面 | M |
| R-32 | 比較表: 型番ごとに店舗別最新価格を横並び表示し、最安店を強調 | M |
| R-33 | 目標価格との差額、最安と2番手の差を表示 | S |
| R-34 | 在庫状態（在庫あり/なし/不明）を記録 | S |
| R-35 | 価格の更新履歴（時系列）を型番ごとに見られる | C |

## 4.5 購入記録

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-40 | 購入（型番・店舗・数量・単価・送料・日付・カテゴリ・メモ）を登録 | M |
| R-41 | 価格記録からワンタップで購入登録へ変換 | M |
| R-42 | 購入の編集・削除（削除は論理削除） | M |
| R-43 | 同一型番の購入履歴と平均取得単価を表示 | S |

## 4.6 予算・集計

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-50 | 月次予算（上限額）を設定 | M |
| R-51 | 当月の支出合計・残額・消化率を表示 | M |
| R-52 | カテゴリ内訳（新弾 / シングル / グッズ / その他）を設定可能な配分で表示 | M |
| R-53 | 予算超過時に警告表示 | M |
| R-54 | 月末までの 1 日あたり残額ペースを表示 | C |
| R-55 | 月次の推移グラフ（直近 6 か月） | C |
| R-56 | 予算の繰り越し（前月残を加算） | C |

## 4.7 新弾情報

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-60 | 商品名・発売日・種別（ブースター/構造デッキ等）・URL の一覧 | M |
| R-61 | 発売日までのカウントダウン表示、発売済みは区別 | M |
| R-62 | 公式商品ページから発売日を取り込む（アプリに直結せず生成 JSON を読む） | S |
| R-63 | 取り込んだ内容を手動で修正・追加できる | M |
| R-64 | 発売日のプッシュ通知 | C |

## 4.8 データ管理

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-70 | 全データを JSON でエクスポート／インポート（復元） | M |
| R-71 | アプリ内で最終エクスポート日時を表示し、未実施なら促す | S |
| R-72 | 端末間同期 | C |

## 4.9 設定

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-80 | 月次予算額・カテゴリ配分・通貨（JPY 固定） | M |
| R-81 | 予算の起点日（月初/給料日など） | C |
| R-82 | データ全削除（確認 2 段階） | S |

# 5. 画面一覧（MVP）

1. **ホーム/ダッシュボード** — 今月の残額、欲しいリスト上位、新弾カウントダウン
2. **欲しいリスト** — 一覧、追加/編集
3. **カード検索** — 日本語名検索 → 型番選択 → 欲しいリストへ
4. **巡回モード** — 店舗選択 → 欲しいカードに価格を入力
5. **比較表** — 型番別の店舗別価格、最安強調
6. **購入** — 一覧、追加/編集
7. **予算** — 月次サマリ、カテゴリ内訳
8. **新弾** — 一覧、カウントダウン
9. **設定** — 予算、店舗管理、エクスポート/インポート

# 6. 非機能要件

| 区分 | 要件 |
| --- | --- |
| オフライン | インストール後は全機能がオフラインで動作（カード検索はローカル索引） |
| 性能 | 一覧表示 200ms 以内、検索入力から結果表示 300ms 以内（1.3 万件規模） |
| 起動 | コールドスタート 3 秒以内（中位 Android 実機） |
| 入力速度 | 巡回モードで 1 枚あたり「数値入力＋次へ」の 2 タップ以内 |
| 対応環境 | iOS Safari 16.4+（ホーム画面追加）、Android Chrome 最新版 |
| 画面 | 360px 幅から破綻しない。片手操作を想定した下部タブ |
| データ保全 | IndexedDB 消失に備え JSON エクスポートを用意。iOS のストレージ退避を許容 |
| アクセシビリティ | コントラスト比 4.5:1、タップ領域 44px 以上 |
| ログ | 個人情報・認証情報を保存しない |

# 7. 用語

| 用語 | 定義 |
| --- | --- |
| 型番 | セットコード＋番号＋レアリティ（例: `QCCU-JP001` / Ultra Rare） |
| 欲しい項目 | 型番＋欲しい枚数＋優先度＋目標価格 |
| 価格観測 | ある店舗である日に見た価格（履歴として蓄積） |
| カテゴリ | 新弾 / シングル / グッズ / その他 |

# 8. 制約・前提

- **対象は遊戯王 OCG（日本語）**。TCG は対象外（英語名の参考表示のみ将来可）
- カードマスタは `DawnbrandBots/yaml-yugi`（公式カードDB由来、`ja` ロケールあり）をビルド時に取り込む
- 画像は扱わない（権利・容量・通信の観点）
- 新弾発売日は公式商品ページ由来のデータを**生成 JSON** として同梱・更新する（アプリから外部サイトへ直接アクセスしない）
- 課金・ログイン・サーバーなし。同期は将来の拡張点として設計だけ確保

# 9. 受入基準（MVP = M1+M2 完了時）

- [ ] 日本語名で検索し、型番を選んで欲しいリストに追加できる
- [ ] 店舗を 3 件登録し、巡回モードで同じ型番に 3 店舗の価格を入力できる
- [ ] 比較表で最安店が視覚的に分かる
- [ ] 比較表から購入を登録でき、残り必要枚数が減る
- [ ] 当月予算 10,000 円に対し 3,200 円購入 → 残額 6,800 円・消化率 32% が表示される
- [ ] カテゴリ内訳が購入内容と一致する
- [ ] 新弾が発売日順に並び、未来のものがカウントダウン表示される
- [ ] 機内モードでも上記すべてが動作する
- [ ] エクスポートした JSON から全データを復元できる
