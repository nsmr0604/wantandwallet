# 1. 背景と課題

遊戯王 OCG のシングルカードを買うとき、複数の実店舗・通販を回って価格を比較している。現状の困りごと:

1. どの店でいくらだったかが記憶とスクショに散らばり、比較できない
2. 「何を何枚欲しいか」を忘れる／買った枚数を二重計上する
3. 今月いくら使ったか、あと何円使えるかが分からない
4. 次の新弾の発売日・定価・予約開始をいちいち調べている

# 2. ゴール / 非ゴール

## ゴール

- 店舗巡回中に、欲しいカードと各店の価格を**その場で数タップで記録**できる
- 巡回後に「どこが最安か」を一覧で判断できる
- 購入実績が**月次予算とカテゴリ別内訳**に自動で反映される
- 新弾の**発売日・定価（パック/BOX）・パック数**を把握し、予約と購入を記録できる
- **オフライン（電波の弱い店内）で全機能が動く**

## 非ゴール（今回やらない）

- カードの売買・マッチング機能
- デッキ構築・対戦記録
- 投資目的の相場分析・自動売買
- 複数ユーザーでの共有・SNS
- ストア配信（App Store / Google Play）
- 新弾の店舗別価格比較（新弾は定価で買う前提のため）

# 3. 利用シーン（想定フロー）

```
[事前] 欲しいカードを名前で登録（数量・目標価格・優先度）
   ↓
[巡回] 店舗を選ぶ → 欲しいリストを上から順に「この店では◯円」を入力
   ↓
[判断] 比較表で最安店・差額・予算残を見て購入を決める
   ↓
[記録] 購入（カード／パック／BOX、数量、実価格、店舗、日付）を登録
   ↓
[振り返り] 月次ダッシュボードで消化率・内訳・買いすぎを確認

[新弾] 発売日・定価・パック数を確認 → 予約を記録 → リマインダーで発売日に気づく
```

# 4. 機能要件

優先度: **M**=Must（MVP）, **S**=Should, **C**=Could（将来）

## 4.1 カードマスタ

**カードは「カード名」だけで管理する。** 再録・型番・セットは同一のカードとして扱う。イラスト違いは「レアリティ」という任意ラベルで区別する。

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-01 | 日本語カード名でカードを検索できる（部分一致・かな正規化） | M |
| R-02 | 検索結果から 1 枚選ぶと欲しいリストへ追加できる（型番選択はしない） | M |
| R-03 | データに無いカードは手入力で登録できる（名前・任意でレアリティ・メモ） | M |
| R-04 | カード画像は表示しない（テキストのみ。将来 C） | M |
| R-05 | 同名カードの重複登録を防ぐ（正規化名で一意） | M |
| R-06 | レアリティ（ノーマル/レア/スーパー/ウルトラ/シークレット等）は**価格・購入記録の任意項目**として保持。カードの同一性には影響しない | M |
| R-07 | 同じカードの再録・別イラストを別カードとして登録しない（統合表示） | M |

## 4.2 欲しいリスト（ウィッシュ）

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-10 | カードごとに「欲しい枚数」「優先度（高/中/低）」「目標価格」「メモ」を登録 | M |
| R-11 | 欲しいリストを優先度・追加日で並べ替え | M |
| R-12 | 購入済み枚数を差し引いた「残り必要枚数」を表示 | M |
| R-13 | 達成（必要枚数＝購入済み）にすると自動でリストから折りたたむ | S |
| R-14 | 希望レアリティを任意で添えられる（表示用。比較はカード単位） | S |

> 購入は「パック/BOX の開封」でも増える。開封分は手動で「購入済み枚数」に加算できる（R-44）。

## 4.3 店舗マスタ

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-20 | 店舗（実店舗／通販）を登録・編集・アーカイブ（論理削除） | M |
| R-21 | 店舗に種別（実店舗/通販）、エリア、URL、メモを持たせる | M |
| R-22 | よく行く店舗をお気に入り（並び順上位固定） | S |

## 4.4 価格記録・比較（シングルのみ）

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-30 | 「カード × 店舗 × 価格 × 日付」を 1 レコードとして記録（履歴を残す）。任意でレアリティを添える | M |
| R-31 | 巡回モード: 店舗を選び、欲しいリストを順に価格入力していく画面 | M |
| R-32 | 比較表: カードごとに店舗別最新価格を横並び表示し、最安店を強調 | M |
| R-33 | 目標価格との差額、最安と 2 番手の差を表示 | S |
| R-34 | 在庫状態（在庫あり/なし/不明）を記録 | S |
| R-35 | 価格の更新履歴（時系列）をカードごとに見られる | C |

## 4.5 購入記録

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-40 | 購入を登録: 対象（カード／パック／BOX）・店舗・数量・単価・送料・日付・カテゴリ・メモ | M |
| R-41 | 価格記録からワンタップで購入登録へ変換 | M |
| R-42 | 購入の編集・削除（削除は論理削除） | M |
| R-43 | 同一カードの購入履歴と平均取得単価を表示 | S |
| R-44 | パック/BOX の開封分をカードの購入済み枚数へ手動加算 | S |
| R-45 | **予約**を記録できる（予約店・予約日・予約価格・発売日）。「予約中」と「購入済み」を区別 | M |
| R-46 | 予約は発売日を過ぎたら「購入済みにする」を促す | S |

## 4.6 予算・集計

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-50 | 月次予算（上限額）を設定 | M |
| R-51 | 当月の支出合計・残額・消化率を表示 | M |
| R-52 | カテゴリ内訳（新弾 / シングル / グッズ / その他）を設定可能な配分で表示 | M |
| R-53 | 予算超過時に警告表示 | M |
| R-54 | 月末までの 1 日あたり残額ペースを表示 | C |
| R-55 | 月次の推移グラフ（直近 6 か月） | C |
| R-56 | 予算の繰り越し（前月残を加算） | C |
| R-57 | 予約中は「予約額」として別枠表示（支出には発売後計上） | S |

## 4.7 新弾情報・定価

新弾は**定価（希望小売価格）で買う前提**のため、店舗別の価格比較はしない。代わりに定価・パック数・予約を管理する。

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-60 | 商品名・発売日・種別・URL・**定価（パック/BOX）**・**1BOX あたりのパック数**を一覧表示 | M |
| R-61 | 発売日までのカウントダウン、発売済みは区別 | M |
| R-62 | 公式商品ページから発売日・定価・パック数を**自動取得**（生成 JSON を読む） | S |
| R-63 | 取り込んだ内容（定価・パック数を含む）を手動で修正・追加できる | M |
| R-64 | 予約開始日・発売日のリマインダー（アプリ内表示。通知は C） | S |
| R-65 | 商品ごとに予約の有無・予約店・予約価格を表示 | S |
| R-66 | 発売日のプッシュ通知 | C |

## 4.8 データ管理

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-70 | 全データを JSON でエクスポート／インポート（復元） | M |
| R-71 | アプリ内で最終エクスポート日時を表示し、未実施なら促す | S |
| R-72 | 端末間同期 | C |

## 4.9 設定

| ID | 要件 | 優先 |
| --- | --- | --- |
| R-80 | 月次予算額・カテゴリ配分・通貨（JPY 固定） | M |
| R-81 | 予算の起点日（月初/給料日など） | C |
| R-82 | **1BOX あたりのパック数の既定値**（既定 30、商品ごとの値を優先） | M |
| R-83 | リマインダーの既定タイミング（予約開始日/発売日の何日前） | S |
| R-84 | データ全削除（確認 2 段階） | S |

# 5. 画面一覧（MVP）

1. **ホーム/ダッシュボード** — 今月の残額、欲しいリスト上位、新弾カウントダウン、予約中
2. **欲しいリスト** — カード単位の一覧、追加/編集
3. **カード検索** — 日本語名検索 → 欲しいリストへ
4. **巡回モード** — 店舗選択 → 欲しいカードに価格を入力
5. **比較表** — カード別の店舗別価格、最安強調
6. **購入** — 一覧、追加/編集（単品/パック/BOX、予約）
7. **予算** — 月次サマリ、カテゴリ内訳、予約枠
8. **新弾** — 一覧、定価・パック数、カウントダウン、予約、リマインダー
9. **設定** — 予算、パック数既定値、店舗管理、エクスポート/インポート

# 6. 非機能要件

| 区分 | 要件 |
| --- | --- |
| オフライン | インストール後は全機能がオフラインで動作（カード検索はローカル索引） |
| 性能 | 一覧表示 200ms 以内、検索入力から結果表示 300ms 以内（1.3 万件規模） |
| 起動 | コールドスタート 3 秒以内（中位 Android 実機） |
| 入力速度 | 巡回モードで 1 枚あたり「数値入力＋次へ」の 2 タップ以内 |
| 対応環境 | iOS Safari 16.4+（ホーム画面追加）、Android Chrome 最新版 |
| 画面 | 360px 幅から破綻しない。片手操作を想定した下部タブ |
| データ保全 | IndexedDB 消失に備え JSON エクスポートを用意。iOS のストレージ退避を許容 |
| アクセシビリティ | コントラスト比 4.5:1、タップ領域 44px 以上 |
| ログ | 個人情報・認証情報を保存しない |

# 7. 用語

| 用語 | 定義 |
| --- | --- |
| カード | カード名で識別される 1 種類。型番・再録・セットは区別しない |
| レアリティ | ノーマル/レア/スーパー/ウルトラ/シークレット等。価格・購入の任意ラベル（カードの同一性には影響しない） |
| 欲しい項目 | カード＋欲しい枚数＋優先度＋目標価格 |
| 価格観測 | ある店舗である日に見た単品価格（履歴として蓄積） |
| シール品 | パック / BOX などの未開封商品 |
| 定価 | 公式の希望小売価格（税込）。新弾は定価で買う前提 |
| 予約 | 発売前の購入予約。予約中と購入済みを区別する |
| カテゴリ | 新弾 / シングル / グッズ / その他 |

# 8. 制約・前提

- **対象は遊戯王 OCG（日本語）**。TCG は対象外（英語名の参考表示のみ将来可）
- **カードは名前単位**。再録・レアリティ・イラスト違いでカードを分割しない
- シングルの価格比較は店舗別に行う。**新弾（シール品）は定価管理で、店舗別比較はしない**
- パック数は商品ごとの値（公式ページから取得）を優先し、無い場合は設定の既定値を使う
- カードマスタは `DawnbrandBots/yaml-yugi`（公式カードDB由来、`ja` ロケールあり）をビルド時に取り込む。セット情報は取り込まない
- 画像は扱わない（権利・容量・通信の観点）
- 新弾の定価・パック数は公式商品ページの構造化データから取得し、**生成 JSON** として同梱（アプリから外部サイトへ直接アクセスしない）
- 課金・ログイン・サーバーなし。同期は将来の拡張点として設計だけ確保

# 9. 受入基準（MVP = M1+M2 完了時）

- [ ] 日本語名で検索し、カードを欲しいリストに追加できる（型番選択なし）
- [ ] 店舗を 3 件登録し、巡回モードで同じカードに 3 店舗の価格を入力できる
- [ ] 比較表で最安店が視覚的に分かる
- [ ] 比較表から購入を登録でき、残り必要枚数が減る
- [ ] 当月予算 10,000 円に対し 3,200 円購入 → 残額 6,800 円・消化率 32% が表示される
- [ ] カテゴリ内訳が購入内容と一致する
- [ ] 新弾が発売日順に並び、定価（パック/BOX）とパック数、カウントダウンが表示される
- [ ] 新弾の予約を記録でき、「予約中」として一覧・予算に反映される
- [ ] 機内モードでも上記すべてが動作する
- [ ] エクスポートした JSON から全データを復元できる
